# EventProgram

## Development server

Run `ng serve` for a dev server. Navigate to `http://localhost:4200/`. The application will automatically reload if you change any of the source files.

## New event
* Change id in src/assets/appEventId
* It invalidates possibly old saved events in localstorage on devices from previous years

## Other event customizations
* set theme in `styles.scss`
* change favicon and name in index.html and manifest.webmanifest
* change icons in manifest.webmanifest
* change app theme color in index.html
* build with --configuration <event name>
